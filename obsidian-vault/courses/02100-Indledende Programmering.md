# 02100 - Indledende Programmering og Softwareteknologi

## Overview

Introduktionskursus i programmering med fokus på Java og grundlæggende softwareteknologi. Kurset danner fundamentet for videre studier i software udvikling.

## Learning Objectives

- Lære Java programmering fra begynderniveau
- Forstå objektorienteret programmering (OOP)
- Anvende grundlæggende datastrukturer
- Udvikle simple programmer og applikationer
- Forstå software development lifecycle

## Key Topics

### Programmeringssprog
- **Java** som primært sprog
- Multi-paradigmatiske sprog (Perl, Python, Scala)
- Funktionel vs. objektorienteret programmering

### Andre Sprog på DTU
- Java
- C, C++, C#
- F# (funktionelt)
- Prolog (logisk)
- Scala (multi-paradigmatisk)

### Programmering Fundamentals
- Variabler og datatyper
- Kontrol strukturer (if, loops)
- Funktioner og metoder
- Klasser og objekter
- Arrays og collections

### Software Engineering Basics
- Kodestruktur og organisering
- Testing
- Debugging
- Version control
