# 02161 - Software Engineering 1

## Overview

Software Engineering 1 introducerer systematiske metoder og værktøjer til at udvikle software i teams. Kurset fokuserer på agile udvikling og praktiske projekter.

## Learning Objectives

- Anvende værktøjer og metoder til software udvikling
- Arbejde med agile software development processer
- Gennemføre projekter fra uformelle, åbne problembeskrivelser
- Håndtere software skalering fra små til store projekter

## Key Topics

### Software Development Process
- [[Software Engineering Principper]]
- Agile Development
- Version Control (Git)

### Project Management
- Håndtering af deadlines og budget
- Risk management
- Scope management

### Software Quality
- Testing strategies
- Bug tracking og fixing
- Documentation

### Scaling Software
Forskellen mellem små og store projekter:
- Små projekter: Direkte bug fixing
- Store projekter: Systematisk proces med flere faser
