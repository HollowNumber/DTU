## How to Use This Vault

### Graph View
Press `Ctrl+G` to open the graph view and visualize connections between concepts.

### Following Links
Click any `[[Concept Name]]` to navigate to that concept's page.

### Lecture References
Each concept links back to specific lectures with page numbers:
`[[2026-02-03-01002-lecture.pdf#page=4|Lecture Date]]`

### Structure
Each concept file contains:
- **Definition** - Formal mathematical/scientific definition
- **Examples** - Concrete examples with calculations
- **Related Concepts** - Links to prerequisite and related topics
- **Covered In** - Lecture references
- **Course** - Which course it belongs to
- **Prerequisites** - What to know first
- **Applications** - Real-world usage
