# Software Engineering Principper

## Definition

Software Engineering handler om at anvende systematiske, disciplinerede og kvantificerbare tilgange til udvikling, drift og vedligeholdelse af software.

## Nøgleproblemer i Software Udvikling

### Projektudfordringer
- Deadlines
- Budget problemer
- Bugs og fejl
- Ændrede kundekrav
- Scope creep (48% af projekter)

### Succesrate for IT-projekter
- ~32% af projekter lykkes
- ~20% fejler fuldstændigt
- ~48% oplever scope creep

## Skalering af Software

**Lille projekt (1-5 personer):**
- Find fejlen
- Ret fejlen
- Opdater dokumentation

**Stort projekt (50+ personer):**
1. Rapporter defekt
2. Indsaml defektrapporter
3. Analyser problem
4. Identificer bug
5. Definer bugfix strategi
6. Fix buggen
7. Test: bug rettet + ingen nye bugs
8. Accepter den rettede version
9. Integrer parallelle ændringer
10. Opdater release dokumentation
11. Release det nye system

## Agile Software Development

Moderne tilgang der fokuserer på:
- Iterativ udvikling
- Fleksibilitet overfor ændringer
- Hyppig leverance
- Tæt samarbejde med kunden
